    - GET /activities Récupérer la liste des activités {
        Cette route permet de récupérer la liste des activités.
        Il est possible de filtrer par statut, par convention, ou par créateur.
        La pagination est également disponible.

        Parameters
        Try it out
        Name	Description
        conventionId
        string($uuid)
        (query)
        Filtrer les activités par convention

        conventionId
        createdBy
        string($uuid)
        (query)
        Filtrer les activités par créateur

        createdBy
        search
        string
        (query)
        Recherche textuelle dans nature et description

        search
        sortOrder
        string
        (query)
        Ordre de tri par date de création (asc = croissant, desc = décroissant)

        Available values : asc, desc

        Default value : desc


        desc
        page
        integer
        (query)
        Numéro de la page (pagination)

        page
        limit
        integer
        (query)
        Nombre d'éléments par page

        limit
        Responses
        Code	Description	Links
        200	
        Liste des activités récupérée avec succès

        Media type

        application/json
        Controls Accept header.
